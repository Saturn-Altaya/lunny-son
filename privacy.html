Политика конфиденциальности приложения «Лунный сон»

Действует с 2 ноября 2026 г.

Коротко: приложение не собирает, не передаёт и не хранит ваши персональные данные на каких-либо серверах. Вся информация остаётся только на вашем устройстве.

Какие данные обрабатываются

Приложение сохраняет на вашем устройстве (в локальном хранилище браузера / WebView):

  • настройки громкости и выбранную звуковую сцену;
  • номера версий для обновления офлайн-кэша;
  • локальную статистику использования (минуты прослушивания, серия дней, достижения).

Эти данные не отправляются разработчику и третьим лицам и удаляются при очистке данных приложения или удалении приложения.

Разрешения

  • Интернет — используется только для первичной загрузки веб-приложения и его обновлений. Аудио (саундскейпы) генерируется непосредственно на устройстве.
  • Уведомления — опционально, только по вашему запросу.

Приложение не запрашивает доступ к контактам, геолокации, камере, микрофону, файлам и сообщениям.

Сторонние сервисы

Приложение не содержит рекламных и аналитических SDK и не использует трекеры.

Дети

Приложение не предназначено для детей младше 3 лет и не собирает данные детей.

Здоровье

Приложение носит вспомогательный релаксационный характер и не является медицинским устройством. Оно не заменяет консультацию врача. При проблемах со здоровьем обратитесь к специалисту.
